# Data Structures and Algorithms

Complete implementations of data structures and algorithms in Java with detailed explanations.

## 📚 Topics Covered

### Data Structures
- **Arrays** - Static and dynamic arrays
- **Linked Lists** - Singly, doubly, circular
- **Stacks and Queues** - LIFO and FIFO structures
- **Trees** - Binary trees, BST, AVL, Red-Black
- **Graphs** - Adjacency list/matrix, traversal
- **Hash Tables** - Hash maps, collision handling
- **Heaps** - Min heap, max heap, priority queue

### Algorithms
- **Sorting** - Bubble, Selection, Insertion, Merge, Quick, Heap
- **Searching** - Linear, Binary, DFS, BFS
- **Dynamic Programming** - Memoization, tabulation
- **Greedy Algorithms** - Optimal local choices
- **Graph Algorithms** - Shortest path, MST
- **String Algorithms** - Pattern matching, KMP

## 🎯 Complexity Analysis

Each implementation includes:
- Time complexity (Big O notation)
- Space complexity
- Best/worst/average case analysis
- Use cases and trade-offs
