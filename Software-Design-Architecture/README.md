Guide to design patterns, SOLID principles, and architectural patterns in Java.

### 1. Design Patterns

- Structural (Adapter, Decorator, Facade)
- Behavioral (Observer, Strategy, Command)

### 2. SOLID Principles
- Single Responsibility
- Open/Closed
- Liskov Substitution
- Interface Segregation
- Dependency Inversion

### 3. Architectural Patterns
- MVC
- MVP
- MVVM
- Clean Architecture
- Layered Architecture
- Microservices

### 4. Clean Code
- Naming conventions
- Code organization
- Comments and documentation
- Refactoring techniques
- Code smells
