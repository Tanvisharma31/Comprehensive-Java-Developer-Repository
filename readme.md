## �️ How to Run Examples

Most directories contain a `src` folder. You can open these in IntelliJ IDEA or VS Code.

**Example**: To run the Algorithm demos:
```bash
javac -d bin Computer-Science/Algorithms/src/main/java/com/google/career/algorithms/AlgorithmExamples.java
java -cp bin com.google.career.algorithms.AlgorithmExamples
```
