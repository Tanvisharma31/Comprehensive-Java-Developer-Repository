# Pomodoro Timer

A productivity timer application implementing the Pomodoro Technique.

## Features

- 25-minute Pomodoro sessions
- Short breaks (5 minutes)
- Long breaks (15 minutes)
- Customizable durations
- Progress visualization
- Session counter
- Persistent settings

## Usage

1. Select a mode (Pomodoro, Short Break, Long Break)
2. Click Start to begin timer
3. Timer counts down with visual progress
4. Get notified when session completes
5. Customize durations in Settings

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage API
