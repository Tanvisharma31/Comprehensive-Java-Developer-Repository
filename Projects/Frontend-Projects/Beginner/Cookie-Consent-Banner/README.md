# Cookie Consent Banner

A cookie consent banner built with HTML, CSS, and JavaScript, using localStorage to remember user preferences.

## Features

- Persistent storage with localStorage
- Accept, Decline, and Customize options
- Smooth animations
- Responsive design
- Remembers user choice

## Usage

Open `index.html` in a web browser. The banner will appear at the bottom. Your choice is saved in localStorage.

## Technologies

- HTML5
- CSS3
- JavaScript
- localStorage API
