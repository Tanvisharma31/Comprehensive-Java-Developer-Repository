# Age Calculator

An age calculator built with HTML, CSS, and JavaScript that calculates age in years, months, and days.

## Features

- Date input validation
- Age calculation in years, months, and days
- Total days calculation
- Beautiful visual display
- Responsive design

## Usage

Open `index.html` in a web browser, select your birthdate, and click "Calculate Age".

## Technologies

- HTML5
- CSS3
- JavaScript
