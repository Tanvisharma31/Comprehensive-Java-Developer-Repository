# Basic Multi-Page Website

A simple multi-page website built with HTML only, demonstrating basic navigation between pages.

## Features

- Multiple HTML pages
- Navigation menu
- Simple styling with CSS
- Responsive layout

## Pages

1. **Home** (`index.html`) - Landing page
2. **About** (`about.html`) - About us page
3. **Services** (`services.html`) - Services listing
4. **Contact** (`contact.html`) - Contact information

## Usage

Simply open `index.html` in a web browser to view the website.

## Technologies

- HTML5
- CSS3
