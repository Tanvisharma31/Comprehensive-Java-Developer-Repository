# Changelog Component

A beautiful changelog component built with HTML and CSS, displaying version history in a timeline layout.

## Features

- Timeline-style layout
- Version history display
- Clean, modern design
- Responsive layout

## Usage

Open `index.html` in a web browser to view the changelog component.

## Customization

Edit the HTML to add your own version history and changelog entries.

## Technologies

- HTML5
- CSS3
