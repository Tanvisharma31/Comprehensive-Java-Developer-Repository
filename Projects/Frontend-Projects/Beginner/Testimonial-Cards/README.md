# Testimonial Cards Layout

A beautiful testimonial cards component built with HTML and CSS, featuring a card-based design.

## Features

- Card-based layout
- Responsive grid design
- Hover effects
- Clean, modern styling

## Usage

Open `index.html` in a web browser to view the testimonial cards.

## Customization

Edit the HTML to add your own testimonials and customer reviews.

## Technologies

- HTML5
- CSS3
