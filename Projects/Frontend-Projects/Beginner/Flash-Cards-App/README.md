# Flash Cards App

A flash cards application built with HTML, CSS, and JavaScript, featuring card flipping animations and progress tracking.

## Features

- Card flipping animation
- Navigation between cards
- Progress tracking
- Score tracking
- Modern, interactive design

## Usage

Open `index.html` in a web browser. Click "Flip Card" to see the answer, then use Previous/Next to navigate.

## Customization

Edit the `flashcards` array in `script.js` to add your own questions and answers.

## Technologies

- HTML5
- CSS3
- JavaScript
