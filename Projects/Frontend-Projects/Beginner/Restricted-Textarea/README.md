# Restricted Textarea with Character Count

A textarea component with character limit and live character counting, featuring a visual progress bar.

## Features

- Character limit enforcement
- Live character count
- Visual progress bar
- Color-coded warnings
- Real-time validation

## Usage

Open `index.html` in a web browser and start typing in the textarea to see the character count update in real-time.

## Technologies

- HTML5
- CSS3
- JavaScript
