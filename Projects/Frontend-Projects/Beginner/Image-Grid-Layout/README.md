# Image Grid Layout

A responsive image grid layout built with HTML and CSS, featuring hover effects and overlay text.

## Features

- Responsive grid layout
- Hover effects
- Image overlays
- Modern design

## Usage

Open `index.html` in a web browser to view the image grid.

## Customization

Replace placeholder images with your own images by updating the `src` attributes in the HTML.

## Technologies

- HTML5
- CSS3
