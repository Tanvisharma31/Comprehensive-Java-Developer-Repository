# GitHub Random Repository Finder

A web app that finds random GitHub repositories using the GitHub API.

## Features

- Random repository discovery
- Repository statistics display
- GitHub API integration
- Modern, clean UI

## Usage

Open `index.html` in a web browser and click "Find Random Repository" to discover random GitHub repositories.

## Technologies

- HTML5
- CSS3
- JavaScript
- GitHub API

## Note

This uses the public GitHub API. No authentication required for basic searches.
