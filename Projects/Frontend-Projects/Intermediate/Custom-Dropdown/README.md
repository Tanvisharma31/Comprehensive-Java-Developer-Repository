# Custom Dropdown

A custom dropdown component built with HTML, CSS, and JavaScript, featuring custom styling and smooth animations.

## Features

- Custom styling (not native select)
- Smooth open/close animations
- Click outside to close
- Selected state indication
- Fully customizable

## Usage

Open `index.html` in a web browser and click on the dropdown to see options.

## Technologies

- HTML5
- CSS3
- JavaScript
