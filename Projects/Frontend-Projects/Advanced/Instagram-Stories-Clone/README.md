# Instagram Stories Clone

A clone of Instagram's 24-hour story UI, featuring progress indicators, navigation, and smooth transitions.

## Features

- Story viewer with progress bar
- Auto-advance to next story
- Navigation (click/tap sides or use arrow keys)
- Keyboard controls (Arrow keys, Space, Escape)
- Smooth transitions
- Responsive design

## Usage

Open `index.html` in a web browser. Click on any story thumbnail to view. Use arrow keys or click sides to navigate.

## Controls

- **Left Arrow / Click Left Side**: Previous story
- **Right Arrow / Space / Click Right Side**: Next story
- **Escape / Close Button**: Close story viewer

## Technologies

- HTML5
- CSS3
- JavaScript
