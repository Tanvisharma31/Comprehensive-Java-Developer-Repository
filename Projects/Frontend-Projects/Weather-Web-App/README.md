# Weather Web App

A frontend web application that displays weather information by integrating with a Java backend API.

## Features

- Search weather by city name
- Display current temperature
- Show weather description
- Display humidity and wind speed
- Responsive design
- Error handling

## Setup

1. Ensure the backend Weather API is running on `http://localhost:8080`
2. Open `index.html` in a web browser
3. Enter a city name and click Search

## Backend Integration

The frontend calls the backend API:
- `GET /api/weather/{city}` - Fetches weather data

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API for HTTP requests

## Usage

1. Start the backend server
2. Open the HTML file in a browser
3. Enter a city name
4. View weather information
