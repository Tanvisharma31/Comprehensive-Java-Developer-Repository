# Quiz App

An interactive quiz application with multiple-choice questions.

## Features

- Multiple choice questions
- Progress tracking
- Score calculation
- Instant feedback
- Restart functionality

## Usage

1. Click "Start Quiz"
2. Answer questions by clicking options
3. View correct/incorrect answers
4. See final score and percentage

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Customization

Edit `script.js` to add/modify questions in the `questions` array.
